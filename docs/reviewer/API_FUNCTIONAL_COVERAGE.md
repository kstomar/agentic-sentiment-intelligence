- Sentiment: nonblank1–5,000 strict text, five supported sources/business types, extra fields forbidden, four sentiment classes, issue/aspect/urgency/summary/next-step schema and exact quotations. Invalid input422; provider/config/auth/rate/timeout/internal failures retain safe codes. The real adapter requests native strict JSON schema, with no successful free-form fallback.
- Investigation: nonblank question≤500,1–10 unique-ID records, allowlisted ActionSelection and validated arguments, bounded deadline/recursion, no checkpoint memory. All four conditional paths execute; forged quotes/IDs/counts and selector/tool injections reject.
- Chat: explicit ANALYZE_TEXT or INVESTIGATE_FEEDBACK, mutually valid mode payload, current feedback required and history rejected. Both response branches and stateless requests pass.
- Batch: required multipart file/text_column, optional ID/date mapping and source metadata; CSV/XLSX validation,2MiB file/100 records/5,000-character row limits. Blank/whitespace explicit source422, omission defaults file_upload. Job IDs32 lowercase hex; pagination bounded. Report/download return202 JobStatus while pending,200 final report/results thereafter. Unsupported file415, oversized413, malformed422; partial row outcomes and tenant/expiry404 pass.
- External REST: required channel plus inherited valid text/source; normalizes feedback_id without granting authority. Signed webhook: required integration/timestamp/delivery/signature headers, authenticated exact body before parse, timestamp/replay/digest checks,202 first acceptance and200 duplicate. Changed bytes or integration collisions409. Status returns lifecycle/safe code only, not raw feedback or analysis.
- Gmail: six API-key operations with three permissions; callback has state authority instead. POST import accepts only strict max_messages1–100 within server cap. No request mailbox/query/tenant selection. State/code/error XOR, duplicates and known-parameter handling are custom route validation, not fully represented by OpenAPI’s independent query fields; documented in the Gmail guide. Job paths32 hex; foreign/unknown404. Status reports local usability, not live Google reachability. Disabled config503. No tokens/raw-body fields; metadata-first attachment skips remain intentional.
- Shared ASGI actual-byte JSON4MiB413, webhook16KiB and multipart2MiB+bounded envelope, authentication-before-body, rolling-rate/intake/model admission429 and body408 are tested. Standard errors use ErrorResponse with request ID. Private headers no-store/nosniff/no-referrer and safe diagnostics are tested. 405 framework method rejection and absent-route404 are framework behavior; not every theoretical framework/proxy error is an advertised business response.
